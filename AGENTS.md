# AGENTS.md

Entry point for AI coding agents working on this repository.

The conventions and contribution mechanics are the same for agents and humans, so the docs are not split by audience. Read these in order:

- [`README.md`](README.md) — what the project is, design goals, status, roadmap.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — how the codebase is organized; includes pointers to per-module deep documentation.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to make changes: project rules, code conventions, the local-checks-mirror-CI discipline.
- [`.github/workflows/ci.yml`](.github/workflows/ci.yml) — canonical list of CI checks. Mirror them locally before pushing.
